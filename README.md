# MotoStock – Entrega 2 (HTML, CSS y JavaScript)
Estructura MVC sin frameworks:
- `index.html`, `html/` → **Vistas** (páginas)
- `css/` → estilos (`base`, `layout`, `responsive`)
- `js/models/` → datos y reglas de validación
- `js/views/` → manipulación del DOM (render, errores, modales)
- `js/controllers/` → eventos con `addEventListener`
- `js/main.js` → punto de entrada
Usa módulos ES: abrir con un servidor (Live Server o GitHub Pages), no con doble clic.
